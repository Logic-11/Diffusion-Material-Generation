# 四组创新方向的交叉比较与立项建议

本比较针对生成器以 MP20 为训练来源，外推生成弛豫后最小平移晶胞仍含 50–100 个原子的材料。四个独立报告共提出十二个候选，每个包含九项论证及停止判据。本阶段完成了科研论证与针对性文献核查，没有训练模型或验证性能。以下优先级是主 Agent 的研究判断。

最值得先做的是能够区分失败原因的实验：周期噪声统计干预、信息可辨识性检验、长波恢复谱和局部错误尾部分析。直接开发完整生成器的证据目前不足。若以全新连接骨架为目标，B2 最直接但风险最大；若接受小母相衍生的新超结构，A3、B3、C3、D3 的物理路线更具体，但它们属于同一个研究家族，不能算四项彼此独立的新颖性。

## 十二个方向的贡献与主要门槛

| 方向 | 可能产生的实质贡献 | 决定是否推进的证据 | 主要边界 |
| --- | --- | --- | --- |
| A1 周期复制与噪声解绑 | 消除对人工周期噪声统计的依赖 | 固定边缘方差和计算量，相关性干预能改善真实大胞恢复及生成 | 超胞增强不能提供新的干净长周期标签 |
| A2 长波慢模加速 | 让正确但缓慢的集体修正在有限预算内完成 | score 方向正确，恢复时间随波长明显增长 | 对错误 score 或需换键的拓扑失序未必有效 |
| A3 有限波矢驱动周期增长 | 让新周期由模式和能量曲率决定 | 比等预算软模搜索发现更多可靠大周期分支 | 外部物理辅助，主要为母相衍生结构 |
| B1 相容局域条件分布 | 将可迁移局部规律组合成一致整体分布 | 条件误差可跨尺寸控制，并改善整体有序 | 相容性不保证唯一长程相或快速混合 |
| B2 周期图全局连接生成 | 直接跨越新的连接拓扑 | 新图可嵌入且弛豫后保留大原胞 | 键图明确的体系优先；拓扑合法不等于稳定 |
| B3 多模竞争与相位锁定 | 解释并选择单模搜索遗漏的大周期 | 耦合项的消融改变分支选择，超过多分支软模基线 | 多模耦合本身已知，须证明新增搜索能力 |
| C1 可辨识零空间 | 区分学得不好与信息不足，定位最少补充信息 | 在合理模型族内构造排序歧义，定向查询优于随机查询 | 不能把限定模型中的结论推广成 MP20 普遍不可能 |
| C2 周期闭合误差理论 | 给出哪些噪声阶段能够跨尺寸迁移的判据 | 误差随预测变量归并，定位干预优于随机时段 | 待证明；局部误差界不保证 SUN |
| C3 能量支持的平移破缺 | 建立几何不可约与物理大周期之间的证据联系 | 非零模式及周期在撤约束、扰动和可靠弛豫后保留 | 相对一个父相降能不等于凸包稳定 |
| D1 局部失败尾部预算 | 用空间错误累积解释尺寸退化并改变训练容量分配 | 局部尾部可迁移且预测整胞失败，优化后保持多样性 | 贯穿晶胞的协同失序可能主导 |
| D2 可信下降方向引导 | 降低外部势将候选引向错误能谷的概率 | DFT 虚功符号及最终产率改善 | 额外物理信息与校准成本；不独立生成新周期 |
| D3 有限幅度破缺延拓 | 自动寻找近似母相，探索有恢复力的大周期能谷 | 超过随机重启及软模搜索的单位成本产率 | 缺少近似母相的结构不适用，不能因此淘汰 |

## 交叉比较得到的关键区别

**A1 与 C2 分别回答干预是否有效及何时可能有效。** A1 是可操作的因果假设，C2 尝试给出周期域、噪声表示和作用范围之间的关系。先检验 A1，无须等待完整定理；C2 也不能仅靠实验相关性宣称推导完成。

**A2 与 B1 的障碍不同。** A2 假定至少部分 score 方向已正确，改善有限时间内的恢复；B1 改变学习对象，关注局部条件是否相容。若方向本身错误，加速不解决问题；若局部规则无法辨识相，增加更新次数也不能凭空补充信息。

**C1 审查的是所有路线的信息来源。** 对一类结构，如果小胞观测相同而目标大周期排序不同，架构可以引入先验，却不能把这个先验称为训练数据提供的证据。C1 的价值在于找到何时信息充分、何时需要哪条额外物理约束，而不是笼统否定尺寸外推。

**A3、B3、C3、D3 应按同一研究家族评估。** A3 负责波矢与平移子群的联系，B3 研究模式竞争和相位选择，C3 强调能量与不可约性的定义，D3 从已有候选反推母相并探索有限幅度路径。独立收敛到此家族说明它具有明确的科学动机，仍不构成实验支持。最强创新候选是能够解释并发现传统多分支软模搜索遗漏的稳定长周期；只有“扩散种子加软模弛豫”时，新颖性不足。

**D1 与 D2 分别对应生成器误差和辅助势误差。** D1 应先验证局部灾难事件确实累积成整胞失败；D2 应先观察物理引导的方向错误。二者即使有效，也可能只提高稳定性而不提高大原胞比例，必须分别测量。

## 必须补齐的技术缺口

1. A1 给出的相关高斯扰动公式尚不是完整的生成算法。须明确相关参数是否作为条件、如何对其边际化，以及时间协方差是否来自合法的前向过程。若使用连续扩散，其协方差增量须满足相应正定条件。训练时已知的复制对应关系，不能在随机大胞采样时当作可用信息。严格共享噪声的奇异分布只适合作单独处理的对照。
2. A2 的 mobility 公式支持固定噪声层内的平稳性。有限步 corrector、外层时间变化及近似 score 仍会引入误差；不能直接称其为完全等价的反向扩散。
3. B1 的统计势不能当作 DFT 能量；MP20 也不是已知温度的平衡分布。B2 的周期连通、图自同构与几何最小原胞是不同检查，Smith 标准形不能单独证明不可约。
4. C2 的指数误差形式是待证明目标。相竞争、声学模和库仑作用可能破坏其假设；先在可解模型验证再谈真实晶体。
5. D1 的联合界控制的是定义明确的局部失败事件；其数字例子不是 SUN 预测。D2 的误差置信界若在分布外失效，“可信下降”就不再是保证。
6. 所有模式路线都要撤掉约束后复验。对一个近似母相的能量优势、一个模式方向的正曲率，均不足以证明完整动力学或热力学稳定。

## 新颖性审查结论

宽泛的相关噪声和物理尺度去噪已有直接近邻。GEODE 已在 Wyckoff 轨道内构造保持对称性的关联噪声并使用笛卡尔坐标扩散；新贡献必须落到跨尺寸周期统计的区别及效果。[GEODE 原文第 4.3 节](https://arxiv.org/html/2610.01898v2)

动态空间群变化也已有方法，不能把“允许对称破缺”单独作为新颖性。[SbCD 原文](https://arxiv.org/html/2608.13457v1)

局域分数的误差分析与去噪中的信息传播均已有理论工作。因此，B1 和 C2 必须说明不同周期域、噪声表示或条件相容性带来的新增问题。[Localized Diffusion Models](https://arxiv.org/html/2505.04417v3)、[Information Spreading in Diffusion Models from Effective Field Theory](https://arxiv.org/html/2608.14308v1)

带平移标签的周期图表示已有 SLICES。B2 的创新应由未见尺寸上的合法组合与物理可实现性证明，不能只诉诸表示替换。[SLICES 原始论文](https://doi.org/10.1038/s41467-023-42870-7)

现有原型依赖的受控测试也提示，按化学式划分未必排除了跨化学组成的同骨架信息。应增加原型或网络家族的留出测试；该论文的有限样本结果不能推成所有生成器只会记忆的普遍结论。[原型依赖受控测试](https://arxiv.org/html/2609.26502v2)

## 建议推进顺序

第一步建立固定生成器的诊断矩阵，先固定组成与晶格，再逐项放开。测量 A1 的相关噪声干预、A2 的长波方向与恢复时间、D1 的局部错误簇。派生超胞用于隔离表示效应；真实大原胞用于独立评测。分开控制原子数、密度、胞形、最短平移长度和噪声的物理幅度。诊断中的受扰恢复不冒充从噪声发现。

同时用 C1 的可解模型验证信息边界，并以 C2 检查周期闭合和噪声表示的不同贡献。这些试验无需先开发完整新生成器。预先限定模型族及反例的物理合理性，避免为了证明不可能而引入任意长程相互作用。

第二步按结果只选择一个主生成假设：若相关性干预有效，推进 A1 并补齐完整随机过程；若方向正确但恢复缓慢，推进 A2；若局部尾部主导，推进 D1；若规则不足以决定长周期，明确引入的物理信息或缩窄结构家族。不要把所有候选堆成一个架构。

若目标优先是新骨架，单独评估 B2 的可嵌入与弛豫保留率；若接受母相衍生的有序超结构，优先检验多模耦合和有限幅度路径是否超过传统强基线。这两类发现分别报告，避免用较窄路线替代自由生成的目标。

## 共同晋级标准

主指标采用全部生成尝试中满足稳定、唯一、新颖且弛豫后最小平移晶胞含 50–100 原子的结构比例。唯一性按匹配簇仅计一次；稳定阈值、能量方法、凸包版本、新颖性参考库和匹配规则预先固定。同时报告 S、U、N、原胞尺寸保留率、局域和整体结构诊断，避免交集变化掩盖具体原因。

对分支搜索须事先固定“尝试”的单位：完整生成轨迹、重启和新增终态分支登记，内部去噪步不能当作独立样本。另报每个初始种子的成功概率、全部终态候选的产率及单位总计算成本的独立发现数，避免不同搜索树用不同分母产生虚假优势。

原胞评价扫描合理的对称容差，并改变弛豫收敛精度复验；报告尺寸随容差的变化，不把某个容差的结果当绝对物理事实。纯复制加微扰是负对照，有独立物理依据的长周期是正对照。缺陷若进入后续任务，其形成能、浓度和镜像作用须独立评价。

所有路线按相同计算预算及多个随机种子比较，并把生成器、外部势、筛查与 DFT 的收益分开记录。只有代理指标改善时保留为诊断贡献；只有纯复制恢复时不计目标成功；不能超过最近邻强基线时，放弃相应的方法创新主张。
