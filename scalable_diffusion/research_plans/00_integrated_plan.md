# MatterGen 大原胞生成的三人近期研究计划

以已经完成的 MatterGen MP20 无条件生成为起点，接下来四周并行检验三个机制：周期噪声统计、长波恢复动力学、局部错误尾部。两周完成最小可行实验，四周决定是否扩大投入。最终目标仍是弛豫后最小平移晶胞包含 50–100 个原子的稳定、唯一、新颖结构；近期交付是可重复的失效诊断和有对照的最小干预，不预先承诺发现率。

方案根据引用对话、本地创新分析与批判审查、当前复现源码制定。以下样本量、阈值和排期是建议实验设计，不是已经完成的实验或性能结果。完整个人方案见 [研究员甲](01_periodic_noise.md)、[研究员乙](02_sampling_dynamics.md)、[研究员丙](03_local_failure_evaluation.md)。

## 三名科研人员的分工

| 负责人 | 独立科学问题 | 近期干预 | 第一项独立交付 |
| --- | --- | --- | --- |
| 甲 | 同一物理晶体换成更大的周期表示，噪声联合统计是否改变去噪能力 | 先冻结模型做相关性干预，再用普通独立噪声做 MP20 派生超胞微调 | 配对周期表示诊断及增强对照 |
| 乙 | 长波修正方向是否正确；若正确，有限采样预算是否不足 | 冻结模型，保持元素离散时间网格，重分配坐标 corrector 次数 | 长波响应谱及等网络调用预算的采样对照 |
| 丙 | 少数局部错误及其空间聚集是否解释整胞失败 | 先诊断，再在严格 MP20 上做困难结构重采样 | 尾部误差的增量预测能力、训练干预和共同评估入口 |

甲改变训练输入的周期表示，乙改变推理计算分配，丙改变训练样本的分配。三者可以使用同一个原始 checkpoint 独立开始，不需要等待另一条线成功。丙承担共享评估规范，但甲乙各自负责将结果按共同格式导出，不能把数据清理和所有后处理都堆给丙。

暂不为 B2 周期图生成、B3 多模物理搜索、全局倒易空间网络单独安排人员。它们需要新的图解码、物理查询或架构验证，会挤占当前最缺少的机制证据。不是否定其价值：第四周若发现局部误差和采样预算都不能解释失败，再决定是否收窄材料族并引入额外信息。

## 现有代码给出的实际起点

实际复现项目位于 `E:/THU/AI2DFT/Diffusion-Material-Generation/diffusion_mattergen`，不是官方 MatterGen 的目录布局。旧对话中的官方路径只能用于方法参考，不能直接作为本地改动清单。

当前缓存 `data_cache/mp_20_mattergen/metadata.json` 记录 train 27,136、val 9,047、test 9,046 个结构；训练输入为 1–20 原子。元数据采用原胞化与 Niggli 约化、晶格矢量按行排列。实验应沿用用户已经训练成功的同一份缓存和 checkpoint，不混用邻近的 CDVAE 预处理缓存。

已经核对的源码约束：

- `scripts/generate.py::generate_batch` 从 `statistic.json` 抽 N。应新增显式 fixed-N 参数，并保留原先默认路径；不覆盖原始训练统计文件。用户的 checkpoint 路径和训练日志需在执行第一天登记。
- `src/diffusion/scheduler.py::PositionVEScheduler.sigma_std` 已有 N 的负三分之一次方缩放。单纯重新加入这一缩放不是新的方法。
- `src/diffusion/crystal_diffusion.py::q_sample` 在注入指定坐标噪声后，仍调用原独立 wrapped score target。相关噪声不能不改目标就用于训练或宣称正确的相关分数误差。
- `src/diffusion/loss.py` 默认按晶体对原子项求和。超胞增强会改变坐标、元素相对于晶格项的权重，必须控制该因素。
- `src/diffusion/sampling/pc_sampler.py::sample_t` 要求联合采样每次恰好走一个元素离散反向步。不得直接把联合采样器改成任意非均匀时间表。
- `src/diffusion/sampling/correctors.py` 的步长依赖 batch 平均范数。机制实验先固定 batch=1；吞吐实验使用相同组成规则和同 N 批次，并做批大小敏感性检查。
- 本地已有 `--mode csp --zero-shot`。可以用 joint 权重夹持元素作诊断基线，但它不等于重新训练过的 CSP 模型，固定晶格还需要独立诊断接口。
- 相邻 `dft` 目录已有双弛豫和静态计算脚本，可复用工作流；实际服务器资源、POTCAR、收敛设置及参考能量兼容性仍需执行前核对。

本次仅检查源码并形成方案，没有修改复现模型、启动训练或提交 DFT。

## 共同数据与信息边界

设立四类数据，并保存不可变 manifest：

| 数据 | 建议首轮规模 | 构造与用途 | 禁止的解释 |
| --- | --- | --- | --- |
| 小胞参考 | MP20 原划分；诊断先选 100 个验证父结构 | 覆盖组成、N、体积和胞形，分为机制开发与留出验证；最终 test 保持封存 | 验证父结构不可进入微调训练 |
| 派生超胞 | 每个父结构选 2–4 个合法整数超胞，N 不超过 100 | 同一父结构不同表示的配对实验；保留原子来源与超胞矩阵 | 不能计为真实大原胞成功 |
| 真实大原胞 | 首轮目标 120 个，60 dev、60 locked test；不足则如实降规模 | 从 MP 获取有序满占位结构，标准化后按 21–49、50–74、75–100 分层；按结构原型成组划分 | 不按输入惯用胞原子数冒充原胞大小；不得用 test 选参数 |
| 评价校准 | 约 20 个小胞母相和约 10 个有独立依据的大周期参考 | 纯复制、弱随机扰动、占据扰动与真实长周期正例 | 随机占据不可默认标签为“不稳定”，需经物理验证 |

真实大胞按其自然原子数分层，不强求正好 64 或 96；固定 N 网格用于生成实验。筛选前可下载较宽的原始晶胞规模，随后原胞化再限定 21–100，避免数据库惯用胞和原胞口径混淆。优先熟悉元素及化学体系，再把新化学组合作独立压力测试。记录与 MP20 的结构匹配、原型匹配及化学重合，不用单一化学式划分代替去重。

MP 数据下载采用官方 `mp-api/MPRester`，需要账号 API key；密钥通过已有环境或本地配置读取，不进入 manifest。若暂无下载权限，甲乙先用本地派生超胞和小胞留出集推进，但“真实大原胞效果”标为待验证，不能用派生数据替代。[Materials Project API](https://docs.materialsproject.org/downloading-data/using-the-api/getting-started)

以下标签必须进入每个 run：

1. **Strict MP20**：生成器的训练输入始终不超过 20 个原子，丙的首轮干预属于此类。
2. **MP20-derived augmentation**：来源仍是 MP20，但展开为大训练输入，甲的增强属于此类。
3. **Physical evaluation/guidance**：记录外部势仅用于后处理评价，还是进入生成决策。若后来把势用于引导，单列其信息与计算成本。

大胞 dev 被反复用来选超参数后，它已提供模型选择信息；不能把整个研发流程称为“完全未接触大胞信息”。locked test 只能在锁定方案后打开。外部势的训练数据覆盖也应单独登记。

## 研究员甲的最小执行方案

甲首先检验两个竞争解释：退化主要来自复制位点的联合噪声变化，或主要来自胞形、物理扰动尺度、图截断与训练分布变化。相关性敏感不自动证明它是自由生成失败的主因。

第一周在冻结模型上完成同父结构对照：

- 先运行原生三字段加噪，量化不同 N、时间和表示的合法去噪误差。
- 再固定同一个超胞、同一时刻与每原子边缘方差，改变复制位点噪声相关系数，例如 0、0.5、0.9。严格共享的端点只作退化对照。
- 相关性构造为 `epsilon_ia = sqrt(rho)*epsilon_i_shared + sqrt(1-rho)*epsilon_ia_ind`；它是可控干预，不直接等价于一套可用的周期相关扩散算法。
- 用几何恢复、方向和配对位移等合适指标评价该干预，不把原独立 target 当作相关分布真 score。
- 相同 t 和相同笛卡尔协方差不能在任意不同胞形之间同时自然保持。因此分开报告“模型原生同 t”和“物理扰动匹配”两种实验，不能声称一次比较控制了一切。

第二周启动最少三个组：原 checkpoint 冻结；原 MP20 继续训练；同预算 MP20 加派生超胞继续训练。先选一个混合比例，例如按原子处理量 25%，不同时搜索四五种比例。仅用训练父结构构造增强，在加载后展开，避免缓存预处理把超胞重新原胞化。

所有微调组使用一致的 loss reduction 与分支尺度策略。若从 sum 改成 mean，额外比较仅改 loss 的对照；甲和丙只有在优化器、预算、loss 策略完全一致时才可共享继续训练基线。训练累计记录原子数、边数、三元组数、optimizer steps 与 GPU 时间，分别报告等原子预算和等时间结果；不假装这些量可以同时精确匹配。

第三至四周仅对有信号的设置增加随机种子和样本量。在真实大胞恢复、从噪声生成、大原胞保留和小胞回归四方面比较。若只恢复复制超胞更好，保留为表示鲁棒性结果，停止扩张“大原胞生成方法”的主张。

## 研究员乙的最小执行方案

乙检验长波模式的修正方向正确但慢、方向本身错误、以及局部误差或元素晶格耦合主导这三种解释。已有频域预条件采样工作，因此近期贡献应落在可重复的晶体尺寸诊断，而不是先宣称预条件算法新颖。

选已知结构及超胞，用分数坐标 f 和整数倒易指标 h 构造可公度位移：

`u_i = a e cos(2*pi*h·f_i + phi)`

使用当前晶格换算真实物理波长，去掉质心平移，检查模式独立性并做低幅度敏感性；同一整数 h 在不同晶格上不是同一波长。首轮可取 0.01、0.03 Å 两档小位移，具体保留范围由线性响应检查决定。

用相同加噪基态的正负扰动计算模型实际笛卡尔更新的差分，避免把基态固有漂移误判为恢复方向：

`response ≈ [update(x+a*u)-update(x-a*u)]/(2a)`

需区分分数坐标 score 的协向量变换与位移的向量变换。最稳妥的主量是实际 predictor/corrector 平均更新映射到笛卡尔后的模式投影。对比有扰动与无扰动轨迹，测方向、收缩率、达到预设振幅阈值所需网络调用数。固定元素和晶格的测试是 oracle 机制诊断；主外推结论另由原生联合 corruption 和自由生成确认。

算法最小改动限定为坐标 corrector 分配：

- 原默认采样器。
- 均匀增加坐标校正次数，作为增加计算的强基线。
- 把同一额外预算集中到 dev 诊断出的噪声区间。
- 在同等长度的随机区间增加同样次数，控制“多计算而已”。

保持元素更新次数、时间网格和晶格流程不变；每次额外坐标更新后重算分数，并按原 Langevin 规则更新随机项。真实网络调用计数优先于用循环次数猜测 NFE。分别比较等 NFE 与等墙钟产率，记录动态图构建成本。

若长波方向主要错误，或把预算放在诊断区间不优于均匀增加，应停止复杂 mobility 的实现。若有稳定效果，再考虑将该采样器与甲或丙单独组合，不能一开始同时改变模型和采样器。

## 研究员丙的最小执行方案

丙要区分“平均误差已经足够解释失败”“少量局部尾部错误额外解释失败”和“整体长程失序主导”三种假说。

在合法前向加噪的已知结构上，计算原子级标准化残差及其平均值、95% 分位、上尾均值；最大值只作辅助，因为它自然随 N 增大。阈值先从训练校准数据按噪声区间确定，避免每个结构固定取 top 5% 又把错误数量当发现。由预注册的周期近邻图分析高误差原子的连通簇和最大簇比例，同时做相同 N、t、元素和误差边际下的空间打乱对照。

用固定协议继续恢复这些已知结构，获得对应的几何失败、弛豫失败和原胞变化标签。比较含 N、t、组成、密度、平均误差的基础统计模型与增加尾部/簇特征的模型，以父结构或结构原型为分组划分和 bootstrap 单位。原子不能视为独立样本；多个噪声种子也不能当多个独立晶体。有额外预测能力仍只是关联，需要后续训练干预检验。

第一轮只实现一种最小干预：训练集内、按固定噪声抽样估计难度的困难结构重采样，保留充分均匀采样概率并限制最高权重。与原 checkpoint、均匀继续训练比较；如难度与 N 强关联，加 N 分层重采样对照。不要同时上 CVaR、原子加权和新架构，避免无法归因。

恢复诊断有真值，自由生成没有真值。不得用真实结构残差去筛自由生成候选；自由生成只能使用可观察的短接触、模型输出、势能、力或不确定性，并逐项说明额外势信息。丙的最终训练干预仍由所有生成尝试的质量和多样性评价。

丙同时维护共同评估入口：轨迹失败登记、结构有效性、弛豫、原胞扫描、结构匹配、稳定性来源、计算成本与结果汇总。甲乙只需输出一致的样本和日志即可接入。

## 共同生成预算与晋级规则

以下是资源未知时的起始预算，不是功效保证：

- 工程 smoke test：N=20、64、96 各 2 条轨迹，查显存、图规模、元素导出和晶格数值问题。
- 冻结基线 pilot：N=20、32、50、64、80、96 各 32 条，共 192 条尝试。包含失败和无法导出的轨迹。
- 第一轮方案比较：仅保留原基线及每条线一个候选；N=20、64、96 每档 128 条，分配到三个独立采样种子集合，而不是每个 seed 再跑 128 条。其中 N=20 是保持小胞能力的回归对照。
- 真正稀有成功的估计需要扩大样本：若一档 128 次零成功，不能宣布不可能；独立 Bernoulli 近似下 95% 上界约为 3/128，即 2.3%，去重依赖还需结构簇分析。
- 训练先做吞吐测量，再为甲丙各分配相同量级的短微调预算。正式结论需要多个独立微调种子；一个训练 seed 的 pilot 只能筛选。
- 至少安排少量每条路线共同规则选出的 DFT 候选和随机审计候选，不只挑最优图。初始目标可为总共 10–20 个，实际以许可、排队和计算成本决定。两周结果不以 DFT 已完成为前提。

生成时失败、OOM 和数值错误分别记录。OOM 可在事先约定的相同随机状态恢复策略下重跑，其成本累计，不能通过删除失败记录改善方法产率。

## 可信评价与物理计算

核心最终指标是：

`R_SUN_large = 满足稳定、唯一、新颖且弛豫后原胞为50–100原子的独立结构数 / 全部生成尝试数`

唯一性采用确定的聚类与代表选择规则，不用生成顺序人为增加计数。同步报告有效率、弛豫收敛率、稳定率、重复率、新颖率、原胞保留率，以及它们的交集；不同条件分母必须写清。

原胞评估至少包括弛豫前后原胞 N、若干合理 symprec 的扫描和更严格弛豫的复核。建议起点 0.001、0.003、0.01、0.03、0.1 Å，范围经正负对照校准后锁定。0.1 Å 可能抹掉真实弱畸变，不要求所有容差一致；记录整个曲线与歧义，而不是挑一个有利容差。元素计数最大公约数为 1 的结构无法按整数份同组成复制约化，这种算术不可约性不能单独证明长程有序。

ML 势弛豫和 DFT 验证分层报告。可以先使用 MatterSim 筛查，但它提供外部信息，而且与 DFT 可能不一致。[MatterGen 官方评价入口](https://github.com/microsoft/mattergen#evaluation)

稳定性阈值应预注册，例如以 E_hull ≤ 0.1 eV/atom 作为“近稳定”筛选，并另报更严格阈值；不把这一阈值称为严格热力学稳定。不把原始 ML 总能量与另一计算层级的 DFT 竞争相能量直接相减构建凸包。若采用官方校准的代理评价，沿用其参考库和兼容流程并显式标为 surrogate。做 DFT 凸包时需要相容的竞争相、元素参考、U、赝势、磁性和能量校正。

相邻现有 VASP 流程可以作为入口；对大胞候选要明确力与应力收敛，并测试加严条件后周期是否保留。相对父相能量降低不是凸包稳定；几何不可约、局部极小和动力学稳定也不是同一结论。

新颖性同时对 MP20 训练集和已登记的较宽参考库计算；只有“超出 MP20”不足以说明材料新颖。只对筛选出的少数结构做 DFT 后，只能报告候选验证率或已确认发现数，不能把该子集比例外推成全体 DFT SUN。若报告确认数除全部尝试，明确它是当前验证流程下的已确认产率，尚未检查者不是已判失败。

## 工作接口与并行合并

共同数据记录至少包含：

`structure_id, parent_id, split, prototype_group, composition, N_input, cell, supercell_matrix, copy_map, source_version, structure_hash`

每次实验至少保存：

`run_id, checkpoint_hash, code_revision, config_hash, training_regime, seed, sample_id, N, t, perturbation_id, NFE, wall_seconds, peak_memory, failure_stage, raw_cif, relaxed_cif, energy_method, hull_reference, primitive_N_vs_tolerance`

建议在复现项目新增一个独立 research 目录放脚本，在现有核心模块做最小接口改动：

- 甲拥有超胞构造、相关扰动诊断和 augmentation 配置。
- 乙拥有 fixed-N 生成接口、轨迹 hook、NFE 计数和 corrector 调度。
- 丙拥有 per-atom 指标 hook、困难结构重采样和评估程序。
- `loss.py` 如甲丙都需修改，由丙维护公共返回接口，甲通过独立配置调用；默认行为保留，并加入与原实现输出一致的回归检查。

固定同一 manifest 和原始 checkpoint 后即可分头执行。首轮单因素比较结束前，不组合增强、尾部重采样和改采样器。只有两项独立有效时才做 2×2 组合：基线、A、B、A+B，观察是否互补，而不是仅比较最终堆叠模型。

软件优先复用当前 PyTorch、图计算与训练环境，记录精确版本；评估另需 pymatgen、spglib、ASE、选定的 ML 势、统计分析工具，下载 MP 需 mp-api。不要为接入官方评估而直接覆盖当前已复现环境，应隔离依赖并做结构/能量字段转换检查。

建议至少有一张能运行当前模型的 CUDA GPU。24 GB 只可作为低 batch 推理的试探资源，50–100 原子带噪周期图的边/三元组与密度可能使显存剧增；不能保证可跑。大显存 GPU 或累计梯度能支持更稳妥微调，但需要实测。只有一张卡时三人并行开发/分析，GPU 作业排队；多卡时甲丙训练和乙推理分队列。CPU 用于数据、对称、匹配和统计；DFT 另依赖服务器、许可及赝势。

第一天测每种 N 的每步用时、NFE、生成秒数、最大显存和 ML 弛豫耗时。用这些测量计算预算：训练时间 = optimizer steps × 实测秒/step；生成时间 = 各 N 的轨迹数 × 实测秒/轨迹。不要从未知硬件直接承诺四周能够跑完固定数量的 DFT。

第四周的决策由科研负责人做出：有干预证据且提高真实大胞结果的机制晋级；仅有代理指标提升的路线保留为机制结论；三个机制都无效时，收窄材料族并检查全局结构信息是否不足，再考虑 B2/B3。没有阳性结果也不应被改写为已证明的信息论瓶颈。
