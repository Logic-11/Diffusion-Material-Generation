# 局部错误尾部与大原胞生成评价实践方案

负责人：研究员丙。近期目标是检验少数局部去噪错误是否导致大胞失败，并用一项小改动验证其因果作用；同时建立三人共用的数据与评价协议。两周完成机制小试，四周决定是否继续投入。以下样本量、阈值和时间表均为拟议实验设计，不是实验结果。

## 科学问题与可证伪假说

研究问题：在平均误差、噪声时刻、原子数和化学组成可比时，局部误差尾部及其空间聚集是否比平均损失更能预测整胞失败？若主动压低尾部，是否能改善真实大原胞生成，而非仅使结构更平滑？

竞争假说如下。

| 假说 | 可观察预测 | 推翻它的证据 |
| --- | --- | --- |
| 局部稀疏错误累积主导 | 高误差位点较少，形成有限大小错误簇；尾部指标增加对失败的跨尺寸预测力 | 控制平均误差和化学后，尾部不增加预测力；减少尾部也不改善整胞质量 |
| 全局协同失序主导 | 局部几何可以合理，长程有序与大周期保留仍失败；错误相关贯穿晶胞 | 局部干预稳定修复大部分失败，并能跨材料家族重现 |
| 化学分布或平均去噪水平变化主导 | 控制元素、局域环境及平均误差后，尺寸与尾部作用明显减弱 | 在同组成配对超胞与真实大胞中仍出现稳定尾部效应 |

联合界 P(至少一处局部失败) ≤ ΣᵢP(Bᵢ) 不要求原子独立；(1−p)^N 则需要额外的独立同分布假设。前者可以作保守描述，后者只作为会被数据拒绝的基线，二者都不是 SUN 的公式。尾部优化已有 CVaR 学习工作；这里可能的贡献是实测的跨尺寸失效机制及其可控干预，而非发明 CVaR。[Soma 与 Yoshida](https://arxiv.org/abs/2002.05826)

## 三人共用数据与划分

**小胞与派生超胞。** 从 MP20 val 分层选 100 个父结构，记录元素组合、N、密度、晶胞长宽比和最短平移长度。用 2、4、8 倍及可用整数超胞矩阵构造 N≤100 的派生结构，每个父结构保留 2–3 个尺寸，另留一组相同 N 但不同胞形对照。保留父原子和复制像映射；划分及 bootstrap 均以父结构为单位，不把各复制像当独立材料。此集只作诊断；丙的训练始终只使用原始 MP20 train。

**真实大原胞。** 优先从 Materials Project 取有序、满占据、21–100 原子的原胞，目标先取得 dev 50–100、sealed test 50–100 个。通过 API 获取结构、ID、数据库版本、结构来源计算与能量方法，先标准化再按原胞 N 筛选。数据库返回的 nsites 不必然等于所需最小原胞原子数；应留出过量候选并自行检查。保留自然存在的 N，按 21–49、50–74、75–100 分箱，不能把真实材料强行复制到 64/96 来充当大原胞。[MP 查询接口](https://docs.materialsproject.org/downloading-data/using-the-api/querying-data)

API 密钥若尚未配置，只需科研人员在运行环境设置，不写进配置、报告或日志。当前已查到的本地数据主要是 MP20；真实大原胞集合尚未被证明已在本地。可先用派生诊断推进，数据不足时公开实际数量，不能以派生超胞替代真实测试。

先去除与 MP20 train 同构的结构，再以组成匿名化的 StructureMatcher 分组为近似原型簇；所有同簇结构只进 dev 或 test 一侧。对边界样本人工检查配位、连接和 Wyckoff 信息，因为匿名几何匹配不等于完整网络家族判别。报告化学熟悉/不熟悉、原型熟悉/不熟悉两维标签，不能仅靠不同化学式宣称全新骨架。由丙保管 sealed test，甲乙只拿 dev；第 4 周锁定方案后统一评估一次。

**评价校准集。** 从 10 个小胞构造纯复制、0.001/0.01/0.05 Å 随机微扰复制；加入约 10 个来源明确、具有有序大原胞的已知结构。前者是几何识别负对照，不预设所有扰动在所有势下都弛豫回母相；后者也必须核验原胞计数。加入同一几何上改变少数占据的对照，记录各元素计数最大公约数 gcd：gcd=1 本身排除了完全等组成的平移复制，但不证明长程有序和稳定性。校准集不可用于调出一个使所有候选都通过的容差。

## 两周机制小试的具体计算

1. 固定 checkpoint、代码提交、数据哈希和随机种子。先在 8 个小胞、8 个大胞上确认 q_sample/predict/残差记录可运行且不更改模型预测。保留官方 joint 前向加噪评估为主；固定组成/晶格仅作另标的受控诊断，不称为无条件生成或已训练 CSP。
2. 在 100 个父结构及其派生超胞、真实大胞 dev 上取 t∈{0.05,0.15,0.30}，每结构每时刻 4 个噪声种子。先审计实际笛卡尔 RMS 噪声；同 t 不能默认等于不同胞形下同物理噪声。主表按原生加噪，另按物理 RMS 分层比较。高噪声另取 t=0.6 作反例，不据此定义低噪声灾难。
3. 定义逐原子维度平均残差 rᵢ=mean_d[(prediction.coord_score_times_std−info.coord_target)²]。这是模型参数化中的训练残差，不能直接叫位移误差或力误差。每晶体保存均值、q90、q95、max、最大 20% 原子均值。N 很小时 top20% 只有 1–4 个原子，需固定 ceil(0.2N) 并报告这一离散效应。
4. 物理空间另外计算短反向步后的周期最小镜像位移误差、最短原子间距、参考邻接关系变化。对倾斜胞使用可靠周期距离，不用简单逐分量 round 当通用最短镜像；维持短时原子对应，发生交换/跨盆地时另标。只在有已知参考结构的恢复任务中使用这些真值误差。
5. 以干净参考的近邻图定义诊断错误簇，按元素族、t 和小胞校准集分位数设严重残差阈值；再统计簇数、最大簇占比、簇半径和周期绕行。清洁图只用于后验分析，不能传入生成模型。短程图可用 4 Å 截断作统一分析起点，并以 3/5 Å 敏感性检验；这是几何邻近而非化学键断言。
6. 从每种尺寸/噪声组合抽约 20 个状态，继续受控恢复，测参考恢复率、碰撞、弛豫失败；共享无条件生成轨迹用于另一个不依赖真值的评价表。各阶段失败分别编码，避免把热力学失败与几何失败压成一个标签。

重要区别：单次 denoising target 是条件目标，其残差也含后验不确定性，尤其高噪声时不能当作模型系统偏差。通过重复噪声、低噪声限制、几何恢复指标三者共同判断。无条件生成时不存在原始 clean target，不能“在线挑最大真实误差原子”；在线只记录碰撞、配位异常、力、密度等可观测代理，并单独校准其与恢复残差的联系。

分析首先比较两个预注册预测模型：F0 使用 N、t、平均误差、密度、胞形及少量元素族变量；F1 再加尾部与簇特征。小样本用正则化 logistic 模型及 grouped cross-validation，报告 held-out log loss、校准误差和置信区间；AUROC 只是辅助。父结构/原型簇整体重采样，不能按原子 bootstrap。化学分层数量不足时合并为粗类别，不拟合数十个稀疏元素系数。

若 F1 仅在混合 N 后更好、同 N 中无增益，不能声称局部尾部独立解释尺寸退化。若均值与尾部高度共线，报告不可识别，改用均值相近的配对结构，不依据回归系数硬分机制。

## 最小训练干预与消融

只在前两周观察到尾部与真实大胞失败有关时继续。第一版选择低噪声坐标尾部辅助项，不同时引入困难样本重采样、能量引导或新 backbone。它增加容量分配偏好，不保证仍是原始精确 score-matching 最优解。

对晶体 c 令 T_c 为最大 ceil(0.2N_c) 个 rᵢ 的均值。定义 w_c=N_c（原配置 reduce=sum 时），若实际 checkpoint 为 mean 则 w_c=1。辅助项为 γ·coord_weight·mean_c[1(t_c≤0.2)·w_c·T_c]，γ 首轮固定 0.1；这是拟议起点，不能由风险界 α/N 推出最优性。不改变 t 分布，避免混入时间重加权。

| 组别 | 训练变化 | 目的 |
| --- | --- | --- |
| C0 | 原 checkpoint，冻结 | 报告当前能力 |
| C1 | 原始损失继续训练 | 排除仅多训练带来的改善 |
| C2 | 同上，加相同系数的低噪声平均坐标项 | 排除仅增加低噪声坐标权重的改善 |
| C3 | 同上，加低噪声 top20% 项 | 检验尾部容量分配 |

首轮各 2,000 optimizer steps、相同 batch 内容和配对 t/noise 序列，学习率先取已有训练学习率的 0.1 倍；恢复同一优化器状态或统一重置，不能混用。时间不够可从 500 步排错起步，但不据此作有效性结论。三个训练组都只用 1–20 原子训练输入，故是 strict MP20。先一组配对 seed 筛选，晋级后对 C1/C2/C3 使用三个训练 seed；每组记录处理原子总数、GPU 时间、峰值显存与更新次数。保留全部 MP20 元素/晶格损失。

增加的代码应提供 `tail_fraction`、`tail_weight`、`tail_t_max` 与 `aux_kind=none/mean/tail`，校验 γ=0 与原损失严格一致，手工小例验证 topk 和 sum/mean 尺度，反向传播有限。无需重写全套训练测试；这些针对损失正确性的校验是必要的。

生成首轮共用 N∈{20,32,50,64,80,96}，每档 32 个，仅用于可运行性和失败类型诊断。晋级比较 N∈{20,64,96}，每档 128 个，重复三个独立采样 seed 集合；不同模型复用相同初始随机数，统计仍按独立生成尝试计。N=20 用于检查小胞退化。128 个零成功只表示产率低且区间宽，不能证明方法理论不可能；对稀有成功需再依据精度目标扩大样本，而不是预承诺千级全部弛豫。

## 共同评价流水线

拟新增 `research_tools/evaluate_denoising.py`、`analyze_error_clusters.py`、`build_large_benchmark.py`、`evaluate_large_cells.py` 和 `audit_dft_results.py`；这些是实施时要创建的文件，并非现在已存在的命令。优先复用已有 CIF、checkpoint、VASP 模块。

每次生成在任何筛选之前登记 attempt_id；字段至少含 method、checkpoint_hash、training_track、N_requested、seed、status、NFE、GPU_seconds、raw_structure、relaxed_structure、energy_method、energy_reference_version、primitive_counts_by_tolerance、match_cluster_id、failure_reason。保存全部失败；OOM 后重新运行同一随机轨迹是执行重试而非新科学样本，但额外成本必须累计，新随机轨迹则是新 attempt。每个状态的初始、ML 势弛豫、DFT 弛豫分别保留，不覆盖。

**结构与不可约性。** 对原始和弛豫结构扫描 symprec∈{0.001,0.003,0.01,0.03,0.1} Å，优先调用 `standardize_cell(to_primitive=True,no_idealize=True)`，不在能量评价前强制理想化几何；返回 None 记为识别失败。主报告用预注册的 0.01 Å，附全曲线。0.1 Å 仅作宽容差敏感性检查，不能要求所有真实微小有序畸变都在该容差保留。[spglib 原胞与标准化 API](https://spglib.readthedocs.io/en/stable/api/autodoc/spglib.cell.html)

在 ML 势下先以 fmax≤0.05 eV/Å 筛选，候选再用≤0.02 eV/Å 复验并核查晶格应力、步数上限和实际最终力；这些为拟议数值，须校准后锁定。以更严弛豫是否消除伪大周期为证据，不能把单次 spglib 大 N 当作真实长程有序。记录 species-count gcd，并分别报告 gcd=1 与 gcd>1。纯复制恢复永远不计真实大原胞发现。

**稳定性。** ML 势弛豫可用已部署且版本锁定的 MatterSim；若已有另一势，则先固定一个，不把换势与模型改动叠加。局域力收敛、低能量或“弛豫没崩”不等于凸包稳定。官方 MatterGen 可进行 MatterSim 评价并读取外部弛豫结构和能量，但具体参考能标必须核验。[MatterGen 评价入口](https://github.com/microsoft/mattergen#evaluation)

只有候选与竞争相能量在同一能标时才报告 E_hull：可选同版本 MLP 重算参考相得到明确标记的 MLP hull，或使用经过验证的参考能校准；绝不能将原始 MLP 能量直接与 MP DFT 竞争相拼成凸包。若两周内没有一致参考能，报告几何有效率、ML 势弛豫收敛率、primitive 保留率和 U/N，稳定列留空，不写 SUN。

DFT 复用已有 relax1→relax2→static 流程，但目前代码没有显式统一负 EDIFFG 力阈值；应记录实际最大力，并为候选设置明确力收敛准则及复验。与 MP 比较须匹配泛函、U、赝势和兼容性校正；仅指定 MPRelaxSet 不自动保证任意本地计算都与某版参考库兼容。[MP 自定义计算能量校正](https://docs.materialsproject.org/methodology/materials-methodology/thermodynamic-stability/thermodynamic-stability/adding-energy-corrections-to-custom-entries)

主筛选阈值可预注册 E_hull≤0.1 eV/atom，并另列更严格阈值分布；应称“达到约定稳定性筛选阈值”，不是宣称绝对热力学稳定。第 4 周可挑 10–20 个代表候选和对照做 DFT，名额由实际服务器吞吐决定，不承诺两周全部完成。按 ML 分数、尺寸、方法分层，并保留随机抽查避免只看最好样本。只验证子集时报告“DFT 验证 x/y 个候选”及选择规则，不能将该比例直接乘回全体称为 DFT SUN。已确认的独立成功数/全部尝试数可报为已验证产率下界；若要估总体需事先设计有已知抽样概率的随机验证。

**唯一与新颖。** 对弛豫后的结构用同一 primitive/StructureMatcher 规则分簇，每簇仅计一次；保存多组匹配容差敏感性。新颖性至少相对于有版本记录的 MP 参考集合，不能仅与 MP20 比较。若只检索了部分化学系统，应称“相对所检索参考集的新颖性”。按化学系统查询所有候选相关已知结构并缓存；不因 N>20 自动计新颖。

主联合指标为已确认 stable、unique、novel 且弛豫后最小平移晶胞含 50–100 原子的簇数/全部生成尝试数。同时单独报告各门槛通过率、原胞 N 分布、整体失序案例、元素及原型多样性和每 GPU 小时的独立候选数。MLP 指标与 DFT 指标分表。

## 资源预算与每天交付

需要已有训练 checkpoint 和完整配置、MP20 缓存、支持 PyTorch 的 GPU、pymatgen/spglib/ASE、分析用 NumPy/Pandas/scikit-learn，以及锁定的 ML 势权重。训练和 MLP 最好分环境，VASP 沿用既有固定版本环境；先导出环境清单再运行，避免升级破坏复现。DFT 另需已有 VASP 许可、赝势和队列资源。文献或库可获取不等于这些本地资源已配置。

显存与工时不作虚构承诺：D1 先测 N=20/64/96 各一个小批次的前向、采样与 MLP 弛豫耗时；大胞从 batch=1 起步。若前向平均耗时 τ，诊断开销约为结构数×时刻数×噪声重复数×τ，再加短恢复；训练预算以实测 100 步时间外推 2,000 步。一个可用训练 GPU 即可串行完成丙的小试，三人并行最好至少把诊断 GPU 与训练 GPU 错峰安排。不要先申请全量百万步重训。

| D1–D2 | 冻结基线、验证逐原子残差与损失尺度 | 数据字典、32/64/96 原子性能 profile、attempt 清单格式 |

| D5–D7 | 错误簇、F0/F1 分组预测及反例 | 容差校准、初版原胞/去重/失败分类工具 |
| D8–D10 | 在真实 dev 上验证尾部迁移；判断是否启动 C1–C3 | 全部方法共同的 baseline pilot 评估 |
| D11–D14 | 500 步排错后 2,000 步单 seed 小试或否定报告 | 冻结评价协议、两周机制结果表 |
| 第 3 周 | 有信号时补三个训练 seed，保持 C2 强对照 | 晋级生成与 MLP 筛查；选 DFT 分层样本 |
| 第 4 周 | sealed test 一次评估，归因与 go/no-go | 跨三路线同预算比较及已有 DFT 结果，不等待全部 DFT 才完成机制决策 |

## 晋级与停止规则

两周晋级需满足：尾部/簇特征在 grouped dev 验证中对失败预测有可重复增益，且不只是平均损失或元素组成代理；至少在两个有足够样本的化学粗类中方向一致。小样本区间跨零时结论是证据不足，而非自动证明或自动否定机制。

四周方法晋级要求 C3 超过 C1 和 C2，降低尾部的同时改善真实大胞恢复或无条件生成的物理评价；需说明多样性、小胞性能和预算代价。若只有碰撞率改善、只有复制超胞恢复改善、或只是总体平均 loss 更小，则保留诊断结果，不声称解决大原胞生成。若 C2 已解释收益，结论转为低噪声权重有效，停止尾部专属创新主张。若全部方法大胞 SUN 为零，报告置信区间与失败构成，不靠严 symprec 或 gcd=1 人为制造成功。

本路线可与甲的超胞增强、乙的采样改动独立运行；首轮不做组合。只有单独效果成立后，再由主负责人选择一个 2×2 小规模交互试验，避免三个改动同时叠加后无法归因。
