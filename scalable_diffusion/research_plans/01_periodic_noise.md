# 研究员甲 周期噪声统计与超胞增强的近期实践方案

目标是在两周内回答：当前 MatterGen MP20 模型的尺寸退化，是否包含可以用最小数据表示改动缓解的噪声统计问题；四周内决定是否继续发展这条方法路线。先冻结模型做干预，再对比普通 MP20 继续训练与独立噪声超胞增强。相关噪声只用于诊断，首轮不开发新的相关扩散 SDE。

当前事实是用户已完成 MP20 无条件生成复现，邻目录存在可读取的联合扩散实现。本方案中的样本量、训练预算和决策门槛是建议预注册的实验设计，不是实验结果；checkpoint 的实际路径、质量指标和 GPU 吞吐仍需在开工日记录。

## 科学问题和竞争解释

研究问题不是“模型能不能输入 80 个原子”，而是：对相同物理结构，不同周期表示与复制位点的噪声相关性是否改变恢复质量？这种差异能否迁移到真实大原胞，而非仅让模型更熟练地恢复小原胞的复制？

| 假说 | 支持它的必要观察 | 与它竞争的解释 |
|---|---|---|
| H1 周期噪声统计是重要因素 | 同一超胞、同一噪声边缘分布，仅改变复制相关性即产生可重复恢复差异；独立噪声增强改善独立大原胞评测 | 差异只反映改变了测试分布或任务难度 |
| H2 主要是尺度和胞形偏移 | 误差与物理噪声协方差、最短周期长度、邻居截断相关，控制后相关性效应减弱 | 原子数本身是主要变量 |
| H3 干净数据支持不足 | 超胞恢复改善，但真实大原胞恢复或自由生成没有改善，输出仍约化为小胞 | 训练预算不足、采样过慢或元素/晶格头失败 |
| H4 主要是训练权重变化 | 改善可由统一损失归一化或普通继续训练复现 | 超胞表示提供了额外可迁移信息 |

MatterGen 已有 N 的负三分之一次方坐标噪声缩放，不能把重新加此缩放当作创新；官方代码及本地 PositionVEScheduler 都可核查此事实。[官方 corruption 实现](https://raw.githubusercontent.com/microsoft/mattergen/main/mattergen/common/diffusion/corruption.py)

GEODE 已构造 Wyckoff 轨道内的相关噪声，用于保持指定对称性。本项目剩余的待验证贡献是“跨周期表示的相关性干预及尺寸外推效果”，不能将相关噪声本身宣称为新方法。[GEODE 第 4.3 节与附录 E.3](https://arxiv.org/html/2610.01898v2)

### 三层数据划分

1. 训练层：只用上述 train split。在线超胞全部由 train 父结构派生，父结构 ID 必须保留。
2. 开发层：从 val 分层抽取 120 个父结构用于完整机制诊断。按父胞 N 分为 1–5、6–10、11–15、16–20 四档，各目标 30 个，再尽量覆盖元素数和胞形；不足的档位全部保留并记录不足。另固定 256 个 val 结构用于小胞性能监测。
3. 锁定测试层：从 test 同规则选取另一组 120 个父结构。在超胞规则、噪声层和晋级门槛冻结后才运行；所有派生样本随父结构一起留出，不能把同一父相的不同超胞放入 train 和 test。

真实大原胞必须另立开发与锁定测试集。建议由研究员丙维护 MP 等来源的共同清单，至少争取 30 个开发结构、30 个锁定结构，均满足弛豫/标准化后原胞含 50–100 个原子；按结构原型分组，兼报熟悉化学空间与更远化学空间。具体材料 ID 和来源版本须实际检索后确定，当前不预设数据库一定提供足量合格结构。真实大胞不参加梯度训练；开发集上做模型选择意味着方法开发接触了大胞信息，须如实写明，最终测试不能反复调参。

没有及时取得真实大原胞时，可以完成表示诊断和超胞实验，但不能以此声称外推到真实大原胞成功。

### 超胞构造方法

为每个父结构保存原始晶格、parent_atom_id、copy_id、整数超胞矩阵 S、密度、N、晶格条件数、最短非零晶格平移长度。

- 选择 det(S) 使 20 < N_parent det(S) ≤ 100。优先每个父结构最多选三种尺度，目标落在约 32、64、96；不能强行声称每个父胞都能构造精确的 50、64、80。
- 首轮只用对角整数矩阵；同一 det(S) 加入尽量均衡与拉长两种胞形，单独检验形状影响。随机非对角矩阵延后。
- 保留 2×2×2 这类各向同比例扩大作为干净尺度对照。它只适用于扩大后不超过 100 原子的父胞子集。
- 在线构造发生在原胞缓存加载之后。不能调用现有默认原胞化预处理重新保存超胞，否则增强会被还原。
- 若新晶格需转换为本地对称晶格表示，必须同步保留坐标、旋转和复制映射的一致性，做笛卡尔距离/体积/元素计数检查。纯旋转后的对称晶格并不改变物理结构。

## 第一周 冻结模型的两组实验

### 实验一 原生联合加噪下的表示外推

每个开发父结构的原胞及至多三种超胞，取六个时间 t=0.05、0.20、0.40、0.60、0.80、0.95，每层五个噪声种子。规模上限为 120×4×6×5=14,400 个结构状态。先用 12 个父结构跑通，再扩至 120。

使用原生 JointDiffusion.q_sample，同一个 t 同时加噪元素、坐标和晶格，保留模型训练的联合噪声语义。计算：

- 每原子归一化的标准化坐标条件目标损失，以及分时间/N/胞形的分布。
- 元素交叉熵、MASK 分组准确率；晶格分数误差。
- 有效体积、最短距离、图边数与三元组数、零邻居/邻居截断比例、奇异晶格失败数。
- 由正确坐标变换得到的笛卡尔分数误差，标明单位；它不是直接的位移误差。
- 低噪声下，以局部展开坐标构造的一步去噪位移估计误差。

原生损失是对已知干净结构的条件分数目标的估计风险。真实加噪数据的边缘 score 不等于某个单样本的条件目标，不能把每个条件误差都解释成网络的纯偏差。配对差异、完整恢复和自由生成仍需一起看。

特别检查 wrapped score 求和截断：现有 max_offset_integer 默认 3。选 20 个样本、低中高噪声，比较更大截断或经过验证的可分离一维精确求和参考。若高噪声参考目标误差已明显，先修正诊断参考，保留原 checkpoint 的原生分布记录，不能把数值截断误差当作尺寸机制。

### 实验二 复制位点相关性干预

在同一超胞、同一 t、同一 A_t 和 L_t 上，仅改变位置噪声：

ε_ia = sqrt(ρ) z_i + sqrt(1−ρ) z_ia，ρ∈{0,0.5,0.9}。

i 是父胞原子，a 是复制编号，所有 z 为独立标准正态。每原子方差不变，复制协方差改变。ρ=1 为奇异对照，仅用于观察复制保持，不用于普通全维高斯 score 或训练。

首轮用 40 个开发父结构、两种超胞、三个低中噪声层、三个 ρ、五个种子，共 3,600 个状态。噪声层从原生扫描中选出，使周期展开仍可靠，不预先把固定 t 当作固定 Å 位移。共享 A_t/L_t 和公共基础随机数可以降低配对比较方差，但不会使任务难度完全一致。

最重要的实现限制：向现有 q_sample 注入相关 position noise 后，它仍会调用独立 wrapped score_target。该 info.coord_target 不能用作相关分布的正确联合标签。诊断脚本必须明确标注 correlation_stress_test，并禁止将其送入 compute_loss 训练。

此实验报告三种可直接观测量：

1. 同一冻结网络给出的更新是否减小相对参考结构的周期对齐 RMSD。
2. 低噪声下的一步重建和有限步修复幅度；阈值、步数对所有 ρ 相同。
3. 与研究员乙共用的模式方向、局部误差簇和恢复曲线。

这些是相关性分布偏移下的鲁棒性测量，不是已经识别“训练时依赖镜像捷径”的充分证据。尤其高相关噪声本来就降低了独立扰动自由度。要把 H1 升格为方法解释，还必须看到独立噪声增强对原生独立噪声的大胞评测有帮助。

固定干净 A、L 的坐标修复可以作为辅助隔离实验，但联合无条件模型在 t>0 时通常看到带噪 A_t、L_t；冻结二者形成额外分布偏移，不能将辅助结果当作标准 CSP 能力。

### 为什么不马上训练相关扩散

在未绕回的坐标中，给定干净 x0 和正定协方差 C 的条件 score 是 −C⁻¹(x−x0)，而不是 −ε/σ。周期 wrapped 情况需对全部相关绕回分支加权，不能逐原子独立求和替代。连续时间还需合法协方差演化、测试时可用条件与对应逆过程。真实随机大胞没有已知 copy_id，不能把训练时的复制标签带入自由生成。

因此四周内保留普通独立噪声的合法训练过程，把相关性作为可证伪的诊断变量。只有结果支持 H1 且数学实现可以独立验证时，才另立相关扩散开发任务。

## 必须分开的尺度控制

本地采用行向量晶格 L、r=fL。独立分数噪声的笛卡尔协方差为 σ_f² LᵀL。N 的负三分之一次方只能在近似同比例放大的胞形下保持物理尺度，不能消除任意超胞矩阵造成的各向异性。

同时保留两张表：

- 原生时间表：相同 t、原生噪声，直接回答实际模型的外推误差。
- 物理幅度表：通过改变 t 尽量匹配 RMS 笛卡尔噪声，记录完整协方差的特征值。此时元素掩码率和晶格噪声也随 t 改变，不能声称所有变量同时相同。

在同一个超胞内比较 ρ 时可同时固定 t、A_t、L_t 和边缘协方差，这是最干净的相关性干预。跨胞形若使用外加各向同性笛卡尔噪声，则必须标为新的压力测试，不再是原生联合扩散分布。不要在噪声生成阶段随意减去质心，否则协方差也被改变；整体平移只在评价对齐阶段去除。

分数坐标 score 是协向量。若 s_f 表示对 f 的梯度，则 s_r=s_f L⁻ᵀ；位置增量则通过 Δr=Δf L 转换。不能把两者都右乘 L。本地 coord_score_times_std 先除以 sigma_x 再按梯度规则转换。低噪声未绕回近似下，Δf=σ_f²s_f 可作为一步去噪位移，但不能扩展为高噪声环面上的唯一干净位置估计。

## 第二周 最小训练矩阵

先固定原子数、元素、晶格扩散定义及 backbone。只改在线数据 transform 和损失统计，所有微调从同一成功 checkpoint 初始化。保留 checkpoint 原采样配置。

| 组别 | 输入 | 目的 |
|---|---|---|
| F0 | 已有冻结 checkpoint | 零新增训练参照 |
| F1 | 原 MP20，原 sum 损失继续训练 | 排除单纯多训练的收益 |
| F2 | 原 MP20，统一归一化损失继续训练 | 排除损失权重变化 |
| F3 | 50% 父结构取原胞、50% 构造超胞，独立原子噪声；同 F2 损失 | 测试派生超胞增强的额外效果 |

50% 是按父结构抽样概率定义；同时报告真正的超胞原子处理占比，不能把它写成 50% 原子。先不扫描 25/50/75% 三个混合比，避免两周变成大规模超参搜索。

与研究员丙复用继续训练对照的条件必须严格：只有初始化、原始损失及 reduce 政策、优化器、时间采样、训练数据抽样、预算和随机种子策略一致，甲的 F1 才能与丙的普通继续训练组共享。甲的 F2 使用新归一化，不能与丙保持原 sum 的对照混用；这两组要分别训练和报告。丙若改用结构难例重采样，也必须保留其自己的均匀抽样对照。

归一化规则：坐标和元素损失各自先除以该晶体 N，再乘一个固定 N_ref；晶格项不变。N_ref 从固定训练校准清单计算并锁定，使原小胞训练的平均尺度尽量接近既有配置。F2 与 F3 完全相同。F1 与 F2 的差别专门用于检查这一目标变化；若只有 F3 相对 F0 好而相对 F2 不好，不能归因于超胞增强。

预算不要同时承诺“等步数、等原子数、等墙钟”三种通常不可兼得的控制：

- 主比较 F2/F3：累计处理相同原子数，记录实际父结构曝光次数、优化步数、边/三元组量与 GPU 小时。
- 敏感性比较：取相同 GPU 小时的 checkpoint 观察结论是否一致。三体图开销可能使每原子成本不同。
- F1 是训练方式对照，另报同墙钟与同原子预算两个截面。
- 显存小则减小每批结构数并梯度累积。当前 train_step 每次清零并立刻 step，梯度累积需要显式实现，不能假设配置项已经存在。
- 使用相同时间采样、学习率、验证时刻和种子策略。建议先试原成功训练学习率的 0.1 倍；这是初值，不是最优设置。

每组先做 200 次优化步吞吐试跑；正式 pilot 的原子预算统一取“各组在不超过 12 GPU 小时内都能完成的共同预算”，并保留每组最高 10,000 步上限。以上是经费上限，不是对完成时间的预测。第一轮 F1/F2/F3 各一个种子；有明确信号再在第 3–4 周对 F2/F3 扩到三个训练种子。

新微调应新开输出目录，不覆盖既有复现结果。init_checkpoint 当前调用 load_joint_denoiser_weights，仅加载 denoiser；它的日志偏向 CSP，但函数本身可加载 joint 去噪器。用于本实验前必须确认所有非学习扩散配置与原 checkpoint 完全一致，或新增明确的 joint warm-start 入口来完整载入模型。不要把更换数据策略的微调伪装成逐步无缝 resume，绕过已有 loader_signature 检查。

## 评价、统计和晋级门槛

研究员甲的主要指标是独立大胞上的原生去噪风险、低噪声结构恢复与小胞性能保留；最终生成必须交给共同评价脚本，不自建另一套 SUN 口径。

每个 F0–F3 先在 N=20、64、96 各生成 64 个样本，共 768 个尝试，用作 pilot；成功组再扩展到共同正式样本量。固定 N 的生成由共用生成入口负责，甲不重复实现采样器。真正目标必须是弛豫后最小平移原胞仍含 50–100 个原子；超胞恢复不能计入目标成功。

统计单位是父结构或真实大胞结构，不是复制原子或噪声状态。按父结构进行配对 bootstrap，并保留所有噪声种子嵌套；多次训练种子作为第二层不确定性，不能只用一个 run 的几千个状态制造虚假的小误差条。

建议在读锁定测试前预注册以下工程门槛，阈值由团队讨论后冻结：

- 机制信号：相关性干预的效果在不同父结构和噪声层可重复，且不能由边缘方差或图故障解释；单有 p 值不足。
- 方法晋级：F3 相对 F2 在真实大胞开发集的主要恢复指标有实际改善，例如相对误差降低至少 10%，并在独立结构 bootstrap 中方向稳定；小胞主要指标退化不超过事先选定容忍度，例如 5%。
- 最终结论：上述阈值只是 pilot 决策门槛；必须在锁定集、多个训练种子以及生成评测中复核，不能用它替代科学结论。
- 停止或降级：只有复制恢复更好、真实大胞无改善；提升仅来自 F1/F2；图工程修复即可解释；或输出弛豫后普遍回到小胞。此时保留机制结果，停止把超胞增强当作充分生成方案。
- 若零个候选通过最终联合指标，报告零与样本量/置信区间，不写“模型不可能外推”。

## 四周交付与资源

| 时间 | 明确交付 |
|---|---|
| 第 1–2 天 | checkpoint/config/data manifest；12 父结构 smoke test；超胞 transform 验收 |
| 第 3–5 天 | 120 父结构原生扫描、40 父结构相关性干预；误差按 N/t/物理长度的图；CPU 高斯参考 |
| 第 6–7 天 | 主要混杂检查；与乙核对 score 方向和坐标转换；冻结微调设置 |
| 第 8–10 天 | F1/F2/F3 吞吐 pilot 与首个预算一致微调；固定验证报告 |
| 第 11–14 天 | 真实大胞恢复、768 个生成 pilot 接共同评测；第一份继续/停止决定 |
| 第 3 周 | 只对有效的 F2/F3 做三种子复核；最多一个补充消融 |
| 第 4 周 | 一次锁定测试；输出方法增益与失败边界；决定是否值得开发更复杂的噪声方法 |

资源规划：沿用成功复现环境；CPU 负责超胞与统计，GPU 负责冻结模型和微调。优先使用现有可运行 GPU，24 GB 可先从单结构 batch 做显存探测，不能承诺默认 512 维三体模型在所有噪声图上都能放入；48–80 GB 或多卡可提高吞吐但不是立项前提。每项实际 GPU 小时由第一天测得的吞吐外推，预留失败与图异常预算。第一周不需要 DFT；ML 势、DFT 和广泛新颖性检索由共同评价任务提供，外部势不参与本线的生成训练。

交给其他两位研究员的接口为：固定结构清单、copy_id/parent_atom_id/S、同一噪声状态、逐原子预测与原生目标、模型 checkpoint 和配置、生成尝试清单。甲接收乙的采样修改前先完成原始采样器评价；初次合并只做“原模型/增强模型 × 原采样器/新采样器”的 2×2 实验，防止叠加后无法归因。

## 对另外两条研究线的审查问题

给采样研究员：模式投影的“正确方向”是相对已知受扰参考，还是相对数据分布真实 score？正方向不自动证明应该加速；同噪声、同 NFE 和同墙钟比较需要分开。别把分数 score 当作笛卡尔位移直接变换。

给评价与局部失败研究员：训练 loss 默认按原子求和，不应把总误差随 N 上升当作局部风险累积。分位数/极值必须按结构统计并控制噪声和元素；真实大原胞的数值不可约性可能只是残余噪声。

甲自己的结论也接受反驳：如果独立噪声增强只加深复制偏好，或结果完全由损失归一化解释，应明确撤回它作为大原胞生成主方法的定位。
